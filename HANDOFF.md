## 1. Что это за проект

`C:\Projects\MoreDance` — мобильное приложение для детей «MoreDance. Спортивные бальные танцы шаг за шагом»:
каталог из 5 танцев, уроки с видео, практика под метроном с камерой-зеркалом, прогресс, PIN-кабинет родителя.

- **Expo SDK 58** (`expo ~58.0.22`), React Native **0.88.1**, React **19.3.0**, expo-router **58**, TypeScript strict.
- Платформы: Android и iOS. iPhone **не проверялся** (нет Mac) — Expo Go из App Store теперь SDK 58, версия проекта совпадает, значит запустится.
- Аккаунты: Expo/EAS пользователь **не входил**, Apple-аккаунта нет.

## 2. Окружение и запуск

```powershell
powershell -File scripts\start-emulator.ps1   # эмулятор Realme_12_Pro_Plus, холодная загрузка, swiftshader
npx expo start                                # Metro; затем клавиша a
```

Важные особенности этой машины:

- **Песочница DSH** блокирует запись в `C:\Users\User\.android`, `C:\Users\User\.gradle`, `~/.npm-cache`, `~/.expo`.
  Поэтому эмулятор, Metro и gradle запускаются только с `sandbox_permissions: danger-full-access`.
  Из-за этого в фоновых задачах их процессы «не видны» ограниченному шеллу, а `adb` иногда показывает `no devices`.
- Права на папку проекта были сломаны (`WRITE_OWNER` отсутствовал) — починены скриптом скилла
  `diagnose-windows-sandbox-acl`. Резервные копии и откат: `C:\Projects\acl-recovery\`.
- Скрипт `scripts/start-emulator.ps1` переписан: по умолчанию **холодная загрузка** + **аппаратный GPU**
  (`-gpu host`, Intel UHD; снапшот на этой машине ронял qemu и восстанавливал чужое приложение на экране).
  Флаг `-FastBoot` возвращает старое поведение, `-SoftwareGpu` — откат на `swiftshader_indirect`.
- **Скорость:** со SwiftShader каждый кадр занимал 89–150 мс (100% janky frames, «Slow issue draw commands»
  в каждом кадре), на `-gpu host` — 17–30 мс (janky 1–14%). Если приложение снова «тормозит и переключает
  вкладки по несколько секунд» — первым делом проверить `adb shell dumpsys SurfaceFlinger | findstr GLES`:
  там должно быть `(Intel) ... Intel(R) UHD Graphics`, а не `SwiftShader`.
- `adb` из ограниченного шелла не умеет писать файлы в проект: снимки экрана делались так:
  `cmd /c "adb exec-out screencap -p > C:\Projects\MoreDance\.expo\shot.png"` с полным доступом.

## 9. Единый визуальный стиль (сделано 03.11)

По просьбе пользователя («сделай всё в одном стиле, чтобы не резало глаза») интерфейс приведён к одной
дизайн-системе. Точка входа — `src/theme.ts`.

### Правила типографики

- **Nunito ExtraBold** (`fonts.bodyExtra`) — все заголовки: экран, раздел, карточка, кнопки.
- **Nunito Bold** (`fonts.bodyBold`) — подписи, списки, «таблетки».
- **Nunito Medium** (`fonts.body`) — основной текст и подсказки.
- **Bebas Neue** (`fonts.brand`) — только цифры (таймер, счёт метронома, показатели), латинские
  названия танцев (WALTZ) и лого-надписи. Раньше Bebas использовался и для заголовков разделов -
  из-за этого заголовки «спорили» друг с другом.
- Готовые роли лежат в `src/theme.ts` → `type`: `hero`, `title`, `screen`, `section`, `cardTitle`,
  `body`, `bodyMuted`, `small`, `caption`, `label`, `strong`, `link`, `button`, `metric`, `timer`.
  Экран выбирает роль, а не размер. У всех ролей задан `lineHeight` (раньше его почти нигде не было,
  поэтому текст выглядел сжатым).
- Радиусы — `radius`: `pill`, `input` (14), `card` (18), `tile` (22). Рамки панелей — `colors.line`
  (нейтральная, а не циановая), поэтому подсветка читается одинаково на всех палитрах.
