# Видео «Взрослой группы»

Сюда кладём ролики взрослых танцев (не бальных).

- Формат: **mp4, кодек H.264** (AAC для звука) - читается и на Android, и на iPhone.
- Имя файла: латиницей, без пробелов, например `hiphop-01.mp4`.
- Превью (необязательно): `hiphop-01.jpg`, кадр 16:9, например 1280×720.
- Вертикальные ролики тоже работают - плеер вписывает их по центру.

После добавления файла нужно прописать его в `src/data/adultGroup.ts`
в массиве `adultVideos` (пример есть в комментарии к массиву).
